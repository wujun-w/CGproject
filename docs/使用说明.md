# 使用说明

本文档说明如何在远程服务器上通过命令行运行本项目，并完成 4 组点云分类实验。

## 1. 项目目标

本项目基于目录中的开源 `PointNet` 与 `DGCNN` 实现，完成以下 4 组实验：

1. `PointNet` 在 `ModelNet40` 上训练与测试
2. `DGCNN` 在 `ModelNet40` 上训练与测试
3. `PointNet` 在 `ScanObjectNN` 上训练与测试
4. `DGCNN` 在 `ScanObjectNN` 上训练与测试

## 2. 依赖安装

先进入项目目录，再安装通用依赖：

```bash
cd /root/autodl-tmp/CG_Project
pip install -r requirements.txt
```

`torch` 不在 `requirements.txt` 中，请根据远程服务器的 CUDA 环境单独安装合适版本的 PyTorch。

## 3. 数据准备

### 3.1 ModelNet40

训练代码默认读取 H5 版本的 `ModelNet40`，路径为：

```bash
data_cg/ModelNet40_h5/modelnet40_ply_hdf5_2048
```

如果远程服务器上还没有这份 H5 数据，请先执行：

```bash
python tools/convert_modelnet40_to_h5.py
```

该脚本会把原始 `.off` 网格转换为 H5 点云数据。

### 3.2 ScanObjectNN

代码默认读取：

```bash
data_cg/ScanObjectNN/main_split_nobg
```

目录下应至少存在：

```bash
training_objectdataset.h5
test_objectdataset.h5
label_mapping.csv
```

其中 `label_mapping.csv` 用于给 `ScanObjectNN` 的整数标签补充官方英文类名映射。

## 4. 训练命令

### 4.0 一键顺序执行全部实验

如果你想在远程服务器上按固定顺序一口气跑完 4 组实验，可以直接执行：

```bash
python run_all_experiments.py
```

该脚本会按下面的顺序逐个启动实验：

1. `pointnet_modelnet40`
2. `dgcnn_modelnet40`
3. `pointnet_scanobjectnn`
4. `dgcnn_scanobjectnn`

每组实验都在独立子进程中运行。单组实验结束后，子进程会退出，显存会随该进程的 CUDA 上下文一起释放，然后脚本再开始下一组实验。

### 4.1 PointNet + ModelNet40

```bash
python main.py --exp pointnet_modelnet40
```

### 4.2 DGCNN + ModelNet40

```bash
python main.py --exp dgcnn_modelnet40
```

### 4.3 PointNet + ScanObjectNN

```bash
python main.py --exp pointnet_scanobjectnn
```

### 4.4 DGCNN + ScanObjectNN

```bash
python main.py --exp dgcnn_scanobjectnn
```

训练过程中，控制台会输出中文提示信息，并显示 `tqdm` 进度条。

## 5. 仅测试命令

如果已经有训练好的最佳权重，可以只做最终测试：

```bash
python main.py --exp pointnet_modelnet40 --mode test
```

如果想手动指定权重文件：

```bash
python main.py --exp pointnet_modelnet40 --mode test --checkpoint results/pointnet_modelnet40/checkpoints/best_model.pt
```

## 6. 结果目录说明

每组实验的结果会保存到独立目录，例如：

```bash
results/pointnet_modelnet40
results/dgcnn_modelnet40
results/pointnet_scanobjectnn
results/dgcnn_scanobjectnn
```

每个实验目录下主要包含：

- `logs/train.log`：训练与测试日志
- `metrics/history.csv`：每轮训练和测试指标
- `metrics/final_metrics.json`：最终测试指标
- `metrics/per_class_accuracy.csv`：每类准确率
- `metrics/wrong_cases.csv`：错误样本记录
- `plots/training_curves.png`：训练曲线图
- `checkpoints/best_model.pt`：最佳权重
- `exports/wrong_cases/`：错误样本点云的 `.ply` 文件

注意：结果字段统一使用英文，便于后续汇总和画图。

## 7. 汇总四组实验结果

完成若干组实验后，可以执行：

```bash
python tools/summarize_experiments.py
```

汇总结果默认保存到：

```bash
results/summary
```

目录下主要包含：

- `experiment_summary.csv`
- `experiment_summary.json`
- `experiment_summary.png`

其中 `experiment_summary.png` 是四组实验的 OA 和 mAcc 对比图，可直接用于报告整理。

## 8. 失败案例分析

最终测试时，程序会自动记录错误样本，并导出对应点云到：

```bash
results/<experiment_name>/exports/wrong_cases
```

可以使用 `MeshLab` 打开这些 `.ply` 文件，分析误分类原因。

## 9. 常见运行顺序

推荐按下面顺序完成实验：

1. `python tools/convert_modelnet40_to_h5.py`
2. `python main.py --exp pointnet_modelnet40`
3. `python main.py --exp dgcnn_modelnet40`
4. `python main.py --exp pointnet_scanobjectnn`
5. `python main.py --exp dgcnn_scanobjectnn`
6. `python tools/summarize_experiments.py`
