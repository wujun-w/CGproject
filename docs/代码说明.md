# 代码说明

本文档说明本项目的代码结构、模块职责和结果保存方式。

## 1. 设计原则

本项目按照“够用即可”的模块化思路实现，目标是完成课程项目最小边界，不做额外扩展设计。

整体原则如下：

1. 只复用开源仓库中的模型定义
2. 不继续使用开源仓库原来的训练脚本
3. 自己统一数据读取、训练、评测、日志和结果导出
4. 四组实验共用一套最小训练框架

本项目使用的两个开源实现来源如下：

- `PointNet`：<https://github.com/fxia22/pointnet.pytorch>
- `DGCNN`：<https://github.com/WangYueFt/dgcnn>

## 2. 顶层结构

```text
CG_Project/
  main.py
  project/
  tools/
  docs/
  results/
  data_cg/
  dgcnn-master/
  pointnet.pytorch-master/
```

## 3. 入口文件

### `main.py`

统一命令行入口。

支持两种模式：

- `train`：训练并自动完成最终测试
- `test`：只加载最佳权重做测试

当前支持的实验名有 4 个：

- `pointnet_modelnet40`
- `dgcnn_modelnet40`
- `pointnet_scanobjectnn`
- `dgcnn_scanobjectnn`

## 4. 配置模块

### `project/config.py`

这个文件直接写死了 4 组实验配置，不使用 `yaml` 或其他配置系统。

每组配置主要包含：

- `model_name`
- `dataset_name`
- `data_root`
- `num_classes`
- `num_points`
- `batch_size`
- `epochs`
- `optimizer_name`
- `lr`
- `scheduler_name`

这样做的目的是减少课程项目中的额外工程负担。

## 5. 数据模块

### `project/datasets/modelnet40_h5.py`

负责读取已经转换好的 `ModelNet40` H5 数据。

单个样本返回：

- 点云 `points`
- 标签 `label`
- 元信息 `meta`

其中 `meta` 包含：

- `sample_index`
- `shape_id`
- `shape_name`
- `split`

### `project/datasets/scanobjectnn_h5.py`

负责读取 `ScanObjectNN` 的 H5 文件。

输出格式与 `ModelNet40` 保持一致，这样训练和评测代码就不需要区分数据集。

此外，该模块会优先读取数据目录中的 `label_mapping.csv`，把整数标签转换成正确的英文类别名，用于：

- 每类准确率表
- 错误样本记录
- 错误样本 `.ply` 文件名

### `project/datasets/transforms.py`

负责最小数据处理流程，包括：

- 点采样
- 归一化
- 训练阶段随机绕 z 轴旋转
- 训练阶段随机抖动

## 6. 模型模块

### `project/models/pointnet_wrapper.py`

包装开源 `PointNet` 分类模型，使其适配统一训练接口。

主要工作：

- 动态加载 `pointnet.pytorch-master/pointnet/model.py`
- 把输入从 `(B, N, 3)` 转成 `PointNet` 所需的 `(B, 3, N)`
- 返回统一格式的输出字典

### `project/models/dgcnn_wrapper.py`

包装开源 `DGCNN` 分类模型。

主要工作：

- 动态加载 `dgcnn-master/pytorch/model.py`
- 把输入从 `(B, N, 3)` 转成 `DGCNN` 所需的 `(B, 3, N)`
- 修补原仓库中 `get_graph_feature` 对 `cuda` 的硬编码
- 返回统一格式的输出字典

### `project/models/builder.py`

统一模型构建入口，根据配置返回 `PointNet` 或 `DGCNN`。

## 7. 训练与评测模块

### `project/engine/trainer.py`

负责训练主流程，主要功能包括：

- 固定随机种子
- 构建数据集和 DataLoader
- 构建模型、优化器和学习率调度器
- 执行每轮训练
- 执行每轮测试
- 保存历史指标
- 保存最佳权重和最新权重
- 保存训练曲线图

该模块会输出中文日志，并把结构化结果保存成英文字段的数据文件。

### `project/engine/evaluator.py`

负责统一测试流程，主要功能包括：

- 计算测试损失
- 计算 OA 和 mAcc
- 统计每类准确率
- 记录错误样本
- 导出错误样本点云

## 8. 工具模块

### `project/utils/metrics.py`

负责计算核心分类指标：

- `oa`
- `macc`
- `per_class_acc`

### `project/utils/logger.py`

实现一个最简单的日志器，同时输出到：

- 控制台
- 日志文件

### `project/utils/io.py`

负责：

- 建立结果目录
- 保存 JSON
- 保存 CSV
- 保存模型权重

### `project/utils/export.py`

负责：

- 保存训练曲线图
- 保存错误样本点云为 `.ply`

## 9. 工具脚本

### `tools/convert_modelnet40_to_h5.py`

一次性预处理脚本，用于把 `ModelNet40` 原始 `.off` 网格转换为 H5 点云数据。

### `tools/summarize_experiments.py`

用于汇总已经完成的实验结果。

输出：

- `experiment_summary.csv`
- `experiment_summary.json`
- `experiment_summary.png`

其中汇总图片会展示不同实验的 OA 和 mAcc 对比。

## 10. 结果保存结构

每个实验的结果目录结构如下：

```text
results/<experiment_name>/
  logs/
  metrics/
  plots/
  checkpoints/
  exports/
```

其中：

- `logs/`：日志文件
- `metrics/`：CSV 和 JSON 指标文件
- `plots/`：训练曲线图
- `checkpoints/`：模型权重
- `exports/`：错误样本导出文件

## 11. 数据字段说明

虽然代码中的提示文字和注释使用中文，但结构化结果字段统一使用英文。

例如：

- `oa`
- `macc`
- `train_loss`
- `test_loss`
- `epoch_time_sec`
- `peak_gpu_mem_mb`
- `wrong_case_count`

这样可以减少后续数据汇总和画图时的额外处理。

## 12. 当前实现边界

当前代码刻意不包含以下内容：

- 复杂配置系统
- 多任务扩展
- 高鲁棒性用户输入处理
- advanced requirement 对应的算法改进
- 额外超参数消融实验

这样做是为了把工作量集中在课程要求的基础部分：四组实验、统一评测、结果记录和失败案例分析。
