# 实验结果总结

本文档对本次点云分类课程项目的正式实验结果进行总结。  
统计范围仅包含以下 4 组正式实验：

1. `PointNet` 在 `ModelNet40` 上训练与测试
2. `DGCNN` 在 `ModelNet40` 上训练与测试
3. `PointNet` 在 `ScanObjectNN` 上训练与测试
4. `DGCNN` 在 `ScanObjectNN` 上训练与测试

说明：

- 本总结**不包含** `smoke_pointnet_modelnet40`
- 本总结**不包含** `dgcnn_scanobjectnn_interrupte`
- 所有结论均基于各实验目录下的 `final_metrics.json`、`training_summary.json`、`history.csv`、`per_class_accuracy.csv` 和 `wrong_cases.csv`

## 1. 总体结果

| Experiment | OA | mAcc | Loss | Best Epoch | Total Train Time (s) | Avg Epoch Time (s) | Peak GPU Memory (MB) |
|---|---:|---:|---:|---:|---:|---:|---:|
| `pointnet_modelnet40` | 87.93% | 85.09% | 0.5070 | 94 | 435.76 | 3.72 | 1109.52 |
| `dgcnn_modelnet40` | 89.87% | 87.08% | 0.3442 | 89 | 2227.56 | 19.53 | 5320.52 |
| `pointnet_scanobjectnn` | 55.25% | 47.18% | 1.4914 | 100 | 128.30 | 0.97 | 1109.42 |
| `dgcnn_scanobjectnn` | 69.02% | 62.68% | 1.0771 | 93 | 543.87 | 4.68 | 5320.45 |

从总体结果可以看到：

- 在两个数据集上，`DGCNN` 的 `OA` 和 `mAcc` 都高于 `PointNet`
- 在 `ModelNet40` 上，两种方法都能达到较高准确率，但 `DGCNN` 仍有稳定优势
- 在 `ScanObjectNN` 上，`DGCNN` 的优势明显扩大，说明其在真实扫描点云上的鲁棒性更强
- `DGCNN` 的精度提升伴随着明显更高的训练时间和显存开销

## 2. 同一数据集上的方法对比

### 2.1 ModelNet40

- `PointNet`：`OA = 87.93%`，`mAcc = 85.09%`
- `DGCNN`：`OA = 89.87%`，`mAcc = 87.08%`

相对 `PointNet`，`DGCNN` 在 `ModelNet40` 上：

- `OA` 提高约 `1.94` 个百分点
- `mAcc` 提高约 `1.99` 个百分点

但代价也很明显：

- 总训练时间由 `435.76s` 增加到 `2227.56s`
- 平均每轮时间由 `3.72s` 增加到 `19.53s`
- 峰值显存由 `1109MB` 增加到 `5321MB`

结论：

- 在规则 CAD 点云上，`DGCNN` 的性能优于 `PointNet`
- 这种提升是稳定存在的，但幅度相对有限
- 如果只看性能，`DGCNN` 更好；如果同时考虑资源成本，`PointNet` 更轻量

### 2.2 ScanObjectNN

- `PointNet`：`OA = 55.25%`，`mAcc = 47.18%`
- `DGCNN`：`OA = 69.02%`，`mAcc = 62.68%`

相对 `PointNet`，`DGCNN` 在 `ScanObjectNN` 上：

- `OA` 提高约 `13.77` 个百分点
- `mAcc` 提高约 `15.50` 个百分点

资源代价方面：

- 总训练时间由 `128.30s` 增加到 `543.87s`
- 平均每轮时间由 `0.97s` 增加到 `4.68s`
- 峰值显存由 `1109MB` 增加到 `5320MB`

结论：

- 在真实扫描数据上，`DGCNN` 相比 `PointNet` 的优势非常明显
- 这说明局部邻域建模和动态图特征提取对复杂噪声点云更有效

## 3. 跨数据集表现分析

为了比较两种方法从标准 CAD 数据到真实扫描数据时的性能变化，可以观察 `OA` 的下降幅度：

- `PointNet`：从 `87.93%` 降到 `55.25%`，下降约 `32.68` 个百分点
- `DGCNN`：从 `89.87%` 降到 `69.02%`，下降约 `20.85` 个百分点

这说明：

- 两种方法在 `ScanObjectNN` 上都明显更难
- `PointNet` 对数据分布变化更敏感
- `DGCNN` 的跌幅更小，跨数据集泛化更稳健

这部分结果能够直接支撑实验计划中的核心论点：  
`DGCNN` 在真实扫描点云上的表现比 `PointNet` 更稳定。

## 4. 收敛情况分析

从 `history.csv` 和 `training_summary.json` 可以看出：

- `pointnet_modelnet40` 的最佳轮次是 `94`
- `dgcnn_modelnet40` 的最佳轮次是 `89`
- `pointnet_scanobjectnn` 的最佳轮次是 `100`
- `dgcnn_scanobjectnn` 的最佳轮次是 `93`

训练过程中的代表性阶段如下：

### 4.1 PointNet on ModelNet40

- 第 `1` 轮：训练 `OA = 35.33%`，测试 `OA = 38.74%`
- 第 `51` 轮：训练 `OA = 90.20%`，测试 `OA = 86.55%`
- 第 `100` 轮：训练 `OA = 94.48%`，测试 `OA = 87.03%`

说明：

- 中前期提升较快
- 后期训练集仍继续上升，但测试集提升有限，存在一定过拟合迹象

### 4.2 DGCNN on ModelNet40

- 第 `1` 轮：训练 `OA = 38.10%`，测试 `OA = 47.49%`
- 第 `51` 轮：训练 `OA = 86.96%`，测试 `OA = 85.29%`
- 第 `100` 轮：训练 `OA = 93.89%`，测试 `OA = 89.79%`

说明：

- 收敛相对平稳
- 后期测试性能仍较高，整体表现优于 `PointNet`

### 4.3 PointNet on ScanObjectNN

- 第 `1` 轮：训练 `OA = 16.76%`，测试 `OA = 21.86%`
- 第 `51` 轮：训练 `OA = 54.14%`，测试 `OA = 49.57%`
- 第 `100` 轮：训练 `OA = 63.97%`，测试 `OA = 55.25%`

说明：

- 数据集更难，收敛速度明显慢于 `ModelNet40`
- 最佳轮次出现在 `100`，说明该模型在当前设置下仍可能没有完全收敛

### 4.4 DGCNN on ScanObjectNN

- 第 `1` 轮：训练 `OA = 12.99%`，测试 `OA = 17.21%`
- 第 `51` 轮：训练 `OA = 59.07%`，测试 `OA = 54.04%`
- 第 `100` 轮：训练 `OA = 74.10%`，测试 `OA = 68.67%`

说明：

- 后期测试性能保持较高水平
- 最佳轮次出现在 `93`，总体收敛情况优于 `PointNet`

## 5. 失败类别与典型混淆

### 5.1 ModelNet40

两种方法都较难识别的类别主要包括：

- `flower_pot`
- `cup`
- `bench`
- `wardrobe`

其中：

- `PointNet` 最差类别是 `flower_pot`，准确率仅 `30.00%`
- `DGCNN` 最差类别也是 `flower_pot`，准确率为 `25.00%`

典型混淆包括：

- `night_stand -> dresser`
- `plant -> flower_pot`
- `flower_pot -> plant`
- `dresser -> wardrobe`
- `table -> desk`

这说明在 `ModelNet40` 上，形状相近、局部结构相似的家具类和容器类更容易混淆。

### 5.2 ScanObjectNN

在真实扫描数据上，困难类别更加明显：

- `bag`
- `box`
- `pillow`
- `toilet`
- `sink`

其中：

- `PointNet` 对 `bag` 的分类准确率为 `0.00%`
- `DGCNN` 对 `bag` 的分类准确率提升到 `23.53%`
- `DGCNN` 对 `box`、`sink`、`toilet` 仍然表现较差

典型混淆包括：

- `display -> cabinet`
- `pillow -> cabinet`
- `box -> bin`
- `bag -> bin`
- `desk -> table`

这些现象说明：

- 扫描点云中的遮挡、残缺和噪声会破坏物体的全局形状
- 类别之间如果局部结构相似，更容易被错误归类
- `DGCNN` 虽然整体更强，但在小样本、结构模糊的类别上仍有明显局限

## 6. 结论

本次实验可以得到以下结论：

1. `DGCNN` 在两个数据集上都优于 `PointNet`
2. 在 `ModelNet40` 上，`DGCNN` 的提升存在但幅度有限
3. 在 `ScanObjectNN` 上，`DGCNN` 的提升非常明显，说明其对真实扫描数据更鲁棒
4. 两种方法从 `ModelNet40` 迁移到 `ScanObjectNN` 时都会性能下降，但 `DGCNN` 的跌幅明显更小
5. `DGCNN` 的优势是以更高的训练时间和显存开销为代价换来的

因此，如果以课程项目的实验结论来概括，可以写成：

> `DGCNN` 在点云分类任务中整体优于 `PointNet`，尤其在真实扫描数据集 `ScanObjectNN` 上表现出更强的鲁棒性和泛化能力；但与此同时，它需要更高的计算资源和更长的训练时间。
